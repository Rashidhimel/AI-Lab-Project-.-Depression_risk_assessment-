# AI-Lab-Project-.-Depression_risk_assessment-
Depression Risk Assessment aims to identify linguistic patterns in social media posts that may be associated with depression-related content. It extracts features from text and applies machine learning models to perform binary classification.

The project emphasizes data validation, user-level data splitting, cross-validation, and evaluation on an independent test set.

Important: This project is for educational and research purposes only. It is not a medical diagnostic tool and must not be used to diagnose depression or make clinical decisions.
